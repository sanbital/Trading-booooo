# Live GPT context amendment — 2026-09-25

Operator explicitly authorized using expanded capture in live GPT entry and exit decisions. This amendment does not establish any profitability or DOA-prediction claim. The original collection protocol and its hash remain unchanged; analyses must separate decisions before/after this input version and retain the existing OOS restrictions on DeepSeek authority.

Version CAPTURE-CONTEXT-1 supplies the latest complete twelve 5-second buckets for each watched symbol. The collector uploads a bounded latest-summary map every 15 seconds through the existing authenticated ingest. No additional LLM calls, trading permissions or new thresholds are introduced. GPT ENTRY, FINAL RECHECK and HOLD receive the same context alongside their existing complete packet, under the existing decision contract. DeepSeek receives no order authority.

The summary contains spread versus recent median, midpoint/depth changes between the first and last bucket endpoints (approximately 55 seconds), buy/sell quote flow over the 60-second window, latest 5-second flow, the largest 1-second sell quote amount in the latest bucket, displayed ask additions/removals per second, and estimated 450-USDT buy/sell VWAP impacts from midpoint. Changes and shares are fractions; spread/impact are basis points; quote amounts are USDT. Displayed liquidity changes do not identify spoofing or distinguish every cancellation from execution. No future labels are supplied.

The database read is service-role-only, read-only and independently switchable through doa_capture.control.gpt_context_enabled (default false). The reader runs alongside existing market reads with a hard 200ms cap. A complete 57–63 second window, continuous buckets, depth coverage and no future timestamps are required. A window ending more than 25 seconds ago is unavailable; freshness is checked again at model serialization. Missing/stale/timeout context is explicitly unavailable, not an automatic veto, exit or ABSTAIN. Existing current quote validation and execution safety remain unchanged.

Costs and limits: at most 32 symbol summaries per upload; the existing 500MB cumulative accepted-byte budget, 1.2GB physical budget, 200k requests, 14-day run and retention remain unchanged. Summary bytes consume the existing budget and may stop collection earlier. No additional model calls; additional input tokens consume the existing GPT daily budget. No guaranteed availability for unwatched symbols, warmup or gaps.

Rollback: set gpt_context_enabled=false to remove usable context without stopping collection; set enabled=false to stop the collector. Restore the saved v89 executor bundle if code rollback is needed. Executor source, order adapters, sizing, protection, deadlines and DeepSeek authority are unchanged. Validate serialized ENTRY/RECHECK/HOLD payloads, advancing-clock timeout, stale/future/gap rejection, private RPC grants and existing order-safety regressions before deployment. Verify real order-free model probes and account readiness after deployment; do not manufacture trades.

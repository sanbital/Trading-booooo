# 청산 개선 코드 — 2026-09-25

상태: 2026-09-25 사용자 요청으로 메인 반영 및 운영 배포를 진행한다. 최종 배포 결과는 EXIT-RELEASE.md에 기록한다.

## 구현

- HOLD/EXIT 완료 시각이 요청 이전, 미래, 비정상 값, 90초 이상 오래된 응답이거나 요청 후 25초를 넘겨 완료됐다면 사용하지 않는다. 시간 청산은 기존 결정적 청산으로 복귀한다.
- 일반 검토 간격 5분은 유지한다. 기존 -1.5% 고점 대비 악화 사건에는 1분 간격을 적용한다. 중복 방지, 재무장 조건, 포지션당 30회 상한을 유지한다. 이는 수익 개선이 입증된 매개변수가 아닌 검증할 정책 변경이다.
- 실제 HOLD 검토의 포지션 수익률·하락률·손절 거리는 새로 읽은 호가의 bid를 사용한다. 요청·수신·거래소 시각을 검증하고 5초를 넘긴 호가는 거부한다. 완료 캔들의 추세 지표와 분리하고 가격 기준·시각을 양쪽 모델 입력에 명시한다. 새 bid가 저장된 최고가보다 높으면 해당 검토 입력의 최고가를 보정한다.
- DeepSeek Flash 독립 검토를 HOLD 패킷 생성 시 연결했다. 기존 검증기, 8초 제한, 재시도 없는 호출을 사용한다. GPT 결과를 먼저 저장하고 DeepSeek 결과는 별도 저널 키에 저장한다. DeepSeek 결과에 주문 권한은 없다.
- 네이티브 손절, 이익 보호 임계값, 포지션 크기, 레버리지를 변경하지 않았다. 진입 판단 계약도 이번 청산 변경 범위에 포함하지 않는다.

## DeepSeek 설정과 비용

배포 승인을 반영하여 서버 비밀 `deepseek api`가 있으면 기본 활성화한다. `DEEPSEEK_HOLD_SHADOW_ENABLED=false` 또는 잘못된 값이면 비활성화한다. 기존 GPT 제어 승인이 충족된 HOLD 검토에만 연결한다. 신규 인증된 `fd1-exit-probe` 경로는 주문 없이 양쪽 실제 API와 저널 저장을 확인한다.

저널의 허용된 purpose `VERIFICATION`, kind `DS_HOLD_SHADOW`, authority 빈 배열을 사용한다. 운영 RPC의 purpose 제약을 읽기 전용으로 확인했다. 기존 원자적 claim과 하루 3 USD/300회 상한을 공유한다. 그러므로 활성화하면 GPT용 예산 여유를 줄일 수 있다. 총 한도를 늘리지 않는다. 사용량이 없으면 0.10 USD 예약을 유지한다. 사용량이 확인되면 모든 입력을 캐시 미적중 최고 요금으로 산정해 예산 상한으로 정산한다(청구서의 실제 금액을 뜻하지 않음). [공식 요금표](https://api-docs.deepseek.com/quick_start/pricing/)의 2026-09-25 기준 입력 0.3/출력 1.2 USD per million을 사용한다. 별도 예산을 갖는 운영 관찰 수집은 추가 저장 구조가 필요하다.

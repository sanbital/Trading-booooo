# Trading-booooo v5.1.0

업비트 **KRW 현물**과 바이낸스 **USDT 현물**을 5분마다 통합 스캔하고, 열린 포지션을 15초마다 감시·청산하는 자기교정형 자동매매 엔진입니다. 브라우저를 열어둘 필요가 없습니다.

## 핵심 구조

```text
Fly.io 고정 egress IPv4 Gateway
  ├─ 5분마다 Upbit + Binance 통합 스캔 호출
  ├─ 15초마다 양 거래소 포지션 감시
  ├─ 거래소별 인증·주문·조회·취소·재조정
  └─ 주문상한·일일매수상한·마켓·중복주문 방어
                         ↓
Supabase
  ├─ market-scanner      추세·구조·호가·체결·비용·이벤트 판정
  ├─ market-autotrader   자금배분·진입·손절·익절·시간청산·회로차단
  ├─ market-learning     실거래/PAPER 성과 학습·승격·롤백
  └─ Postgres            추천·주문·체결·포지션·손익·학습 증거 영구 저장
                         ↓
Upbit KRW Spot / Binance USDT Spot
```

Supabase Edge Functions는 고정 발신 IP가 아니므로, 거래소 인증 주문은 고정 egress IPv4를 가진 별도 게이트웨이만 실행합니다. API 키는 Fly Secret에만 저장합니다.

## 실행 주기

- 전 종목 통합 스캔: 5분
- 포지션 감시·손절·익절: 15초
- 실전 포워드 학습: 매시간
- 450일 워크포워드 교정: 매주

## 최초 상태

API 키를 등록해도 최초 모드는 `PAPER`입니다. 제한 실거래는 GitHub Actions의 `Auto Trading Control`에서 다음 확인을 거쳐야 시작됩니다.

```text
command: start_live_limited
confirmation: ENABLE_LIVE
```

## 기본 안전선

- 현물만 허용
- 업비트는 `KRW-*`, 바이낸스는 `*USDT`만 허용
- 시장가 매수 금지, 지정가 IOC 진입만 허용
- 청산 목적의 시장가 매도만 허용
- 출금·입금·이체·마진·선물·레버리지 기능 미구현
- 총 동시 보유 4개, 거래소별 최대 2개
- 동일 기초자산의 양 거래소 중복 노출 차단
- 종목당 총자산 최대 5%, 거래당 위험예산 0.5%
- 업비트 1회 100,000원/일 300,000원, 바이낸스 1회 100 USDT/일 300 USDT 기본 상한
- 일일 손실 1.5%, 주간 손실 3%, 연속 손실 3회에서 신규 진입 차단
- 기존 수동 보유 종목에는 자동 진입하지 않음
- 실제 잔고가 봇 장부보다 작으면 신규 진입 자동 정지
- 주문 결과가 불명확하면 동일 client identifier로 조회하며 중복 주문하지 않음

## 자기교정

실제 종료 거래는 같은 후보의 가상 결과보다 우선합니다. 실거래는 PAPER보다 더 높은 가중치로 학습됩니다.

학습 항목:

```text
실제 평균 체결가와 슬리피지
실제 수수료 추정 및 순손익
MFE / MAE
손절·목표·추적·시간청산 원인
고점 포착률
거래소·마켓별 성과 편향
```

포워드 학습은 주간 워크포워드 안전선보다 진입 기준을 느슨하게 만들 수 없습니다. 충분한 BUY 표본, 양의 기대수익, Profit Factor, 낙폭, 종목 집중도, 롤링 검증을 모두 통과한 challenger만 승격되고 최근 성과가 악화되면 이전 프로필로 롤백됩니다.

## 설치

[`DEPLOYMENT_AUTOTRADE.md`](./DEPLOYMENT_AUTOTRADE.md)를 순서대로 실행합니다. 필요한 Secret 목록은 [`SECRETS_v5.1.0.md`](./SECRETS_v5.1.0.md), 빌드 검증 범위는 [`VALIDATION_v5.1.0.md`](./VALIDATION_v5.1.0.md)에서 확인합니다.

자동매매와 자기교정은 손실 가능성을 줄이기 위한 구조이지 수익을 보장하는 장치가 아닙니다. 급격한 가격 갭, 거래소 장애, 유동성 고갈, API 정책 변경에서는 계획보다 불리하게 체결되거나 청산이 지연될 수 있습니다.
